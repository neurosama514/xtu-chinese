# 翻译流程

本项目共约 1900 条文案，全部以 TSV 形式保存在 `translations/`，可分四步复现。

## 步骤 1：抽取候选文案

```powershell
.\build.ps1 -Stage tools
.\build.ps1 -Stage extract
python .\src\scripts\candidates.py     # 从 dump_orig.tsv 选出界面文案
python .\src\scripts\prep_tasks.py     # 生成 task_*.tsv（带 id，供翻译）
python .\src\scripts\prep_round2.py    # 生成含 {0} 占位符的模板串
```

产出（都在 `work/`）：

| 文件 | 内容 |
|---|---|
| `task_baml.tsv` | 界面 BAML 文本（317 条去重） |
| `task_knob.tsv` / `task_monitor.tsv` | 调参项、监控项元数据 |
| `task_perftune*.tsv` | PerfTune.exe 里的代码字面量 |
| `task_xtucommon*.tsv` | XtuCommon.dll 里的代码字面量 |
| `task_themes*.tsv` | 主题 XAML 里的大段说明 |

格式为 `id <TAB> kind <TAB> 英文原文`。

## 步骤 2：翻译

对每个 `task_*.tsv` 产出同 id、同顺序的 `tr_*.tsv`，格式 `id <TAB> 中文`。
必须遵守：

- 保留**行首/行尾空格**（很多是拼接片段，如 `" has been ignored."`）
- 保留 `{0}` `{1}` `{0:F2}` 等占位符
- 术语统一，参照 [`GLOSSARY.md`](GLOSSARY.md)

本项目的译文由 AI 分批翻译 + 人工统一术语产出，已全部提交在 `translations/`。

## 步骤 3：生成补丁映射

```powershell
python .\src\scripts\build_maps.py     # BAML 映射、XML 改写、字符串映射、资源映射
python .\src\scripts\patch_themes.py   # 主题 XAML 替换
python .\src\scripts\extra_strings.py  # 补充：压力测试、单字标签
```

产出在 `work/apply/`：

- `baml_map.tsv`：`文件/index → 译文`
- `strmap_*.tsv`：`原文 → 译文`（Cecil 按 `ldstr` 精确匹配）
- `KnobMetadata.xml` / `MonitorMetadata.xml` / `Category.xml` / `*ColorTheme.xaml`：改写后的资源
- `resmap_*.tsv` / `neut_sdk.tsv`：资源替换表与签名校验绕过表

## 步骤 4：应用并打包

```powershell
.\build.ps1 -Stage patch       # 写回安装目录（自动备份）
.\build.ps1 -Stage installer   # 生成单文件安装包到 dist/
```

## 增量修改译文

改 `translations/tr_xxx.tsv` 后重新跑步骤 3、4 即可；`work/` 可以随时删除重建。
